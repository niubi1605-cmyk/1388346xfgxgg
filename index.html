1私人播客怎么用？

创建后会生成 两个链接：📤 浏览链接（给朋友看）和 ✏️ 管理链接（自己改）。

关键：改内容用管理链接进去改，不要重新点生成。

视频链接仅存字符串（几十字符），不会撑爆数据。封面可选。

2东西托管怎么用？

上传文件 → 本地 AES-256-GCM 加密 → 生成专属链接。别人打开链接直接下载，无需登录。

密钥通过 URL 的 # 部分传递，永远不会发送到服务器。服务端只有密文。

能否分享：如果本页面是从公网网址打开的（GitHub Pages / Vercel 等），链接可以分享；如果是本地双击 HTML 打开，链接是 file:// 开头，朋友打不开。

3短视频下载 API 都失败？

公开 API 由社区维护，可能集体失效。工具已做自动切换和超时保护。

建议：① 稍后重试 ② 复制链接到浏览器手动打开 ③ 换其他平台链接

4数据保存在哪里？

待办、便签用浏览器 localStorage 保存在本机。私人播客文字内容存在 jsonblob.com（公开 JSON 服务），访问链接由随机 ID 生成。
