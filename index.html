1这次修复了什么？

核心改动：主页不再依赖任何外部 CDN。

之前网站打不开，很可能是因为某个 CDN 加载失败导致整个脚本报错。现在外部库（JSZip、QRCode、HLS.js）全部改为按需异步加载，只有真正用到对应工具时才会加载。加载失败也只影响那一个工具，主页和其他工具照常使用。

2为什么之前用不了了？

可能原因：

  • CDN 被墙 / 加载超时，导致整个脚本挂掉
  • 某个 API 检测请求卡住，阻塞了后续代码
  • 某个新 API（如 crypto.randomUUID）在旧环境不存在

现在这些都修了：所有外部依赖按需加载、所有异步操作都有超时、所有不兼容的 API 都做了兼容处理。

3私人播客和东西托管还在吗？

在。私人播客和东西托管都保留，但做了稳定性优化。

私人播客：视频链接仍只存字符串，数据体积实时显示。

东西托管：文件在本地用 AES-256-GCM 加密后上传，密钥通过 URL 片段传递，服务器只存密文。

4东西托管的链接能发给朋友吗？

看你怎么打开这个网站。

  • ✅ 从公网网址打开（GitHub Pages / Vercel / Netlify / 自己的服务器）→ 生成的链接可以分享给朋友，朋友打开就能下载
  • ❌ 本地双击 HTML 文件打开 → 链接是 file:// 开头，只有你能打开，朋友打不开

想让朋友能下载，先把这份 HTML 部署到 GitHub Pages 或 Vercel，得到一个公网网址。

🔒隐私承诺

核心处理工具全部本地运行。

播客数据：文字内容存储在 jsonblob.com。访问链接由随机 ID 生成，不可猜测。

东西托管：文件在本地加密后才上传，服务端只见到密文。解密密钥通过 URL 片段（# 之后）传递，浏览器不会发送 URL 片段给服务器。所以服务端永远无法解密你的文件。
