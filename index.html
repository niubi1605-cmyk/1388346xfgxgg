1私人播客怎么用？

创建播客后生成两个链接：📤 浏览链接（给朋友看）和 ✏️ 管理链接（你自己留着改）。

💡 关键：改内容请用管理链接进去改，不要重新点生成——重复点会新建储物柜。

📎 媒体支持：封面完全可选。视频链接支持 .mp4、.m3u8（HLS 流媒体）、.webm、云盘直链等任意可访问地址。

2为什么提示数据过大？

M3U8 链接本身只有几十字符，绝对不可能撑爆数据。真正占空间的是：

  • 单集文字稿：一段 5000 字的文字约 15KB
  • 封面图片：压缩后约 30-80KB
  • 单集数量：30 期每期 5000 字 = 约 450KB

报错时会显示占用分析，明确告诉你哪部分占最多。建议：减少单集文字内容，或减少期数。

3朋友访问有网络限制吗？

没有任何网络限制。只要朋友能上网就能打开：

  • ✅ 4G / 5G / WiFi / 公司网 / 校园网
  • ✅ 你在北京、朋友在广州
  • ✅ 你手机关机了，朋友照样能看

4M3U8 视频播放失败？

M3U8（HLS）播放对浏览器有要求。点上方「🌐 浏览器推荐」标签查看推荐列表和解决方法。

简单说：Safari / Chrome / Edge 95+ 都能播；Firefox 和部分老浏览器可能不行。

🎯 为什么要推荐浏览器？不同浏览器对 M3U8（HLS 流媒体）的支持不同。用对浏览器，播客的 M3U8 视频就能正常播放。
⚠️ 国内浏览器说明：QQ、360、搜狗、UC、夸克等大多基于 Chromium 内核（同 Chrome），都能正常播放 M3U8。如果你的浏览器是这些，一般不用换。
💡 如果都播不了怎么办？直接复制 M3U8 链接，用 VLC / IINA / PotPlayer / MX Player 等本地播放器打开。这些播放器原生支持 HLS，一定能播。
💡 视频链接可以是任何可访问的地址，不限于图床。只要浏览器能打开就能用。
1M3U8 流媒体（推荐）

形如 https://example.com/video.m3u8。常见于直播、在线视频、IPTV。本工具内置 HLS 播放器。

优点：链接极短（通常 100 字符内），不占空间。

2直链（.mp4 / .webm）

形如 https://example.com/video.mp4。点开就是文件本身。任何支持直链的图床、云盘、自建服务器都可以。
