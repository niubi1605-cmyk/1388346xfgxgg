1私人播客生成器怎么用？

创建播客后会生成两个链接：📤 浏览链接（给朋友）和 ✏️ 管理链接（自己改）。

关键：改内容请用管理链接进去改，不要重新点生成。

为什么不会卡了？视频链接仅存字符串（通常 <200 字符），不再嵌入数据。数据体积实时显示，不会超出限额。

2东西托管怎么用？

上传任意文件（APK/视频/图片等），设置有效期（3 分钟到永久），生成专属链接。

别人打开链接会看到「🐮 一头牛东西托管」页面，直接下载，无需登录。

加密：文件在本地用 AES-256-GCM 加密后再上传，密钥通过 URL 片段传递，永远不会发送到服务器。服务端只存储密文。

3朋友访问有网络限制吗？

没有任何限制。只要能上网就能打开：4G/5G/WiFi/公司网/校园网都可以。

更新同步：页面开着最多 20 秒自动同步；刷新立即最新。

🎯 不同浏览器对 M3U8（HLS）支持不同。用对浏览器，视频就能正常播放。
⚠️ 国内浏览器（QQ/360/搜狗/UC/夸克）大多基于 Chromium 内核，都能播 M3U8。
📡 短视频解析 API 池：按顺序尝试，失败自动切换。任一成功即停止。
⚠️ 所有 API 由第三方社区维护，可用性随时间变化。本工具做了超时保护和自动切换，全部失败时会给出明确提示。

🔒隐私承诺

核心处理工具全部本地运行。

播客数据：文字内容存储在 jsonblob.com（公开 JSON 服务）。访问链接由随机 ID 生成，不可猜测。

东西托管：文件在本地加密后才上传，服务端只见到密文。解密密钥通过 URL 片段（# 之后）传递，浏览器不会发送 URL 片段给服务器。所以服务端永远无法解密你的文件。
